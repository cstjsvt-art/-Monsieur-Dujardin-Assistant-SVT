Application Streamlit de téléconsultation pédagogique destinée aux élèves de 3e.

Fichiers

app.py : application principale

requirements.txt : dépendances Python

blessure_main.png : image de la blessure utilisée dans la consultation

Secret Streamlit

Ajouter dans les Secrets de l'application :

OPENAI_API_KEY = "votre-cle-api"

Fonctionnalités

dialogue élève / patient

progression pédagogique sur l'inflammation et la phagocytose

sauvegarde / reprise par code (stockage local non garanti sur Community Cloud)

génération d'un bilan final

téléchargement direct du bilan au format PDF
